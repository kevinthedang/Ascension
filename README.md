* [Example Mod from tModLoader](https://github.com/tModLoader/tModLoader/tree/1.4.5/ExampleMod)


## Core Gameplay Loop

1. Spawn in the Hub
2. Prepare and select a path
3. Enter combat encounters
4. Defeat enemies, elites and bosses
5. Earn upgrades and relics
6. Create powerful build synergies
7. Push deeper into the run
8. Defeat the final boss (hopefully)
9. Start a new run with a different build
